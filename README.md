# Codelab

A personal lab for sharpening programming skills across languages — small exercises, Advent of Code solutions, data structures & algorithms, and language fundamentals.

## Structure

| Directory     | Focus                                                         |
|---------------|----------------------------------------------------------------|
| [`c-lab`](c-lab)         | Low-level C, x86_64 assembly, reverse engineering & debugging |
| [`go-lab`](go-lab)       | Go fundamentals, DSA, and Advent of Code (2021–2024)          |
| [`julia-lab`](julia-lab) | Julia / Pluto.jl notebooks                                    |
| [`math-lab`](math-lab)   | Math problem write-ups and solutions                          |
| [`python-lab`](python-lab) | Python fundamentals and coding-interview style drills       |
| [`rust-lab`](rust-lab)   | Rust fundamentals and Advent of Code                          |

Each subdirectory is self-contained with its own README where relevant.
